# eiraman/.github

Default community health files for every repository of the Eiraman organisation: contributing guide
(with the DCO rules), code of conduct, security policy, issue and pull request templates, and the
organisation landing page in `profile/README.md`. A repository that has its own copy of one of these
files overrides the default.

Status: **draft**. Placeholders in `<...>` (contacts, links) are filled when the organisation is created.
The organisation name `eiraman` is itself a placeholder until it is confirmed.
